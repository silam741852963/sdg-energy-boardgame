# Image assets

## `earth-blue-marble-global.jpg`

This 2048 × 1024 JPEG is a resized derivative of NASA Visible Earth's
*August, Blue Marble Next Generation with Topography and Bathymetry*. It contains
Earth imagery only: no NASA insignia, logotype, identifiable person, or separate
third-party artwork is included.

`RocketScene` uses the texture in both the opening crash approach and the
post-mission Earth return. `Renderer` projects the equirectangular map onto a
tessellated, rotating, GPU-lit sphere and targets Ōmagari, Akita at 39.453083 N,
140.475444 E.
