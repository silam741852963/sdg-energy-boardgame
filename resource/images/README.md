# Image assets

## `earth-blue-marble-global.jpg`

2048 x 1024 cutscene derivative of NASA Visible Earth's *August, Blue Marble
Next Generation with Topography and Bathymetry*. The global equirectangular map
is projected onto a rotating sphere by the GPU, and allows the crash camera to
target Ōmagari, Akita's real coordinates (39.4531 N, 140.4754 E).
